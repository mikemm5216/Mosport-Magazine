## Build and QA

- Run `npm ci`, `npx playwright install --with-deps chromium`, `npm test`, then `node scripts/build-public-pages.js dist-public`. A new output path is required on each invocation; build refuses an existing path.
- `dist-public/public-release-manifest.json` records the exact build `GITHUB_SHA` and SHA-256 per included file. The release bundle is **only** the contents of `dist-public/`, never the full `site/` directory or repository root.
- `tests/unit/public-pages.test.js` independently checks the built artifact against its exact whitelist and manifest, enforces production script order, non-disclosure of fixtures and owner JS, no team logos, source reference existence, and refusal to overwrite an existing destination.
- The GitHub Actions workflow verifies on PR, deploys **only on main** after the tests pass; neither PRs nor Drafts are deployed.

## Deployment prerequisite

GitHub repo Pages metadata was `has_pages=false` at M6 inception. GitHub Pages requires the repository admin to select **Settings → Pages → Build and deployment → Source: GitHub Actions**. A repository GitHub App without Pages administration rights cannot make this change. Once it is enabled, trigger `MOSPORT M6 public-only GitHub Pages` via Actions → Run workflow if the first main push failed before Pages was enabled. Link the public URL only after its deployment succeeds, inspect actual HTTP and bilingual 390/1440 browser readback, and retain the release SHA and rollback commit.

GitHub Pages is public even when the source repository is private; do not upload private edition files to this repo or artifact. The owner-only ChatGPT Site is separate and is not a dependency of M6.
