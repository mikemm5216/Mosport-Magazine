# Internal locked World consumer

Dependency: NBA draft #76, exact producer commit
`1a4365c17db5dd5e2482365d32d151523c4bf17f`, on NBA #75. This branch is
stacked on Magazine #15 (`194214764ddb432172286b5c985927b4d1445257`), which
contains #14. Their existing branches and validators are unchanged. Facts and
leader inputs still require NBA #69/#70; no missing inputs are manufactured.

`site/js/contracts/locked-world.js` consumes `mosport-a/locked-world-inspection@1`.
It validates the strict envelope, ordered lock hash, canonical artifact hash,
chronology, stage, source snapshot binding and unchanged World v1 package.
An explicit trusted pin object must contain exactly `gameId`, `stage`,
`lockFingerprint`, `inspectionFingerprint`. Obtain it separately from an approved
artifact manifest. Hashes detect corruption and version substitution; they do
not authenticate an issuer. Deriving pins from the uploaded payload defeats this
boundary. This implementation does not create a manifest or trusted transport.

The adapter calls unchanged #14/#15 inspectors with only the validated embedded
World package. Invalid optional inputs return their existing refusal, with no
facts/players. Expired, withdrawn and superseded packages retain internal audit
metadata but hide optional observations. No INITIAL/FINAL fallback or latest
revision guessing occurs. LATE_RECORDED remains explicit and cannot be described
as timely prediction. The unchanged 15-minute receipt TTL can expire before
FINAL. There are no public probabilities or rendering routes.

## Offline command

```
node scripts/inspect-locked-world.js --inspection /approved/inspection.json --pins /trusted/pins.json
```

Optional `--facts` and `--leaders` supply their separate files. Default time is
current UTC, evaluated at invocation. `--now` is historical inspection only and
output is labelled `EXPLICIT_REPLAY`. This is a one-shot file inspector, not a
live page, subscription or live revocation channel. A cached artifact cannot
know about an unseen withdrawal. A supplied withdrawal revision needs a refreshed
trusted artifact pin, even when the immutable lock remains the same.

No UI is changed. Browser acceptance of existing #14/#15 remains separate.
No fetch, capture, DB writes, public issuance, deployment or fee is introduced.

## Executable verification

`node --test tests/unit/locked-world.test.js` covers strict pins, both hashes,
negative chronology, exact expiry, withdrawal revision, FINAL/INITIAL separation,
optional-record binding and read-only CLI. All fixture data is SYNTHETIC TEST DATA,
never evidence about a real game or forecast. The fixture
`tests/fixtures/a-world/synthetic-locked-inspection.a.json` was generated by the
exact #76 producer above using its `synthetic-scoreboard.json`, an in-memory DB,
observation 2027-10-14T20:00Z, capture 20:05Z, INITIAL 20:10Z, export 20:11Z,
and a test-only injected store clock. The producer/consumer check is protocol
compatibility, not proof of a prospective real-world run or rights qualification.
